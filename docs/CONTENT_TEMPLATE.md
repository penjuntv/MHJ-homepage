# 발행 템플릿 — 새 글 한 편의 뼈대

D3 결정("정형 삽입물만 규격화")의 실행본. **글의 목소리는 규격화하지 않는다** — 문단의 리듬, 무엇을 쓸지,
어떤 사진을 고를지는 두 분의 몫이다. 여기 있는 건 검색·AI 답변 엔진이 읽는 **뼈대**뿐이다.

이 문서의 항목은 전부 코드가 실제로 검사하거나 렌더한다. 손으로 외울 필요는 없고, 글을 저장하면
폼 아래 "발행 전 체크리스트"가 남은 것을 말해 준다(`lib/blog-preflight.mjs`).

---

## 본문 순서

### 1. 답 먼저 — 첫 문단 40~60단어

제목이 던진 질문에 **첫 문단에서 답한다**. 배경 설명이나 그날의 날씨로 시작하지 않는다.
AI 답변 엔진이 인용하는 건 대개 이 문단이고, 검색 결과의 스니펫도 여기서 나온다.

> Year 7 in New Zealand is the first year of intermediate school, and most children start it at eleven.
> Terms run from February to December, and the timetable changes to specialist teachers …

이야기체 글(편지·일기)은 이 규칙을 적용하지 않아도 된다 — 체크리스트에서 경고만 뜨고 저장은 된다.

### 2. H2 소제목 3개 이상, 그중 하나는 질문형

독자가 훑어볼 수 있게, 그리고 글 안에 목차가 생기게 한다(H2 가 3개 이상이면 상세 페이지 위에
"On this page" 목차가 자동으로 붙는다).

질문형 소제목 하나는 그 자체로 검색어가 된다: `What changes in Year 7?`

### 3. Key takeaways — 제목 + 불릿 3~5개

본문 어디든(보통 답 먼저 문단 다음) 이렇게 쓰면 **서버가 자동으로 박스로 감싼다**:

```
## Key takeaways
- Year 7 starts at intermediate school.
- Most children are eleven.
- Terms run February to December.
```

감지 규칙(`lib/content-html.mjs`):
- 제목 텍스트가 `Key takeaways` / `Takeaways` / `핵심 요약` / `한 줄 요약` 중 하나(콜론·마침표는 허용)
- 그 **바로 다음**이 불릿 목록이어야 한다. 사이에 문단이 끼면 박스가 안 만들어진다
- 중첩 목록(목록 안의 목록)은 감싸지 않는다 — 평면 3~5줄로

### 4. 본문

### 5. 내부 링크 2개 이상 (허브 1개 포함)

지금 발행 80편 중 내부 링크가 아예 없는 글이 10편, 2개 이상인 글은 7편뿐이다. 색인에서 고립된
글은 검색에 잘 안 나온다.

폼 아래 "관련 글 · 내부 링크" 패널이 후보를 점수순으로 보여준다 — **링크 복사**를 눌러 본문에
붙여넣으면 된다(패널이 본문을 대신 고치지는 않는다).

### 6. 외부 권위 링크 1개 이상

정부·학교·공식 기관. 사실을 확인해 주는 근거이자 신뢰 신호다.
링크가 살아 있는지는 발행 전에 `fact-verify` 스킬로 확인한다.

### 7. 인포블록 (선택)

`info_block_html` — 표·체크리스트·용어 정리처럼 본문과 결이 다른 정보. 유씨팩토리 산출물이 여기 들어간다.

### 8. FAQ 2~3개

폼의 FAQ 칸에 질문·답변으로 넣는다. 글 하단에 Q&A 로 보이고, 같은 내용이 구조화 데이터
(FAQPage)로도 나간다 — 검색 결과에 접힌 질문으로 노출될 수 있다.

질문은 독자가 실제로 검색창에 칠 문장으로: `When does Year 7 start?` (○) / `Year 7 정보` (×)

## 폼에서 채우는 것

| 칸 | 기준 | 왜 |
|---|---|---|
| `seo_title` | 30~60자 | 검색 결과·공유 카드 제목. **지면 제목은 그대로 둔다** — 감성적인 제목과 검색용 제목을 나눠 쓰는 장치다. 비우면 글 제목이 그대로 쓰인다 |
| `meta_description` | 120~160자 | 검색 결과의 설명문 |
| 한국어 요약 | 2~3문단 | 영어 정본 뒤에 `<section lang="ko">` 로 붙는다. 한국 독자·네이버용 |
| 커버 캡션 | 한 줄 | 표지 사진 아래 이탤릭. **처음 발행할 때는 필수** |
| 공유 카드 이미지 설명 | 장면 서술 | `og:image` 의 alt. 제목을 그대로 옮기지 않는다 — "A school bag on the kitchen table" 처럼 |
| 관련 글 | 2~3편 | 글 하단에 이 순서로 나온다 |
| 태그 | 3~7개 | 태그 페이지와 관련 글 추천이 이걸 쓴다 |

## 본문 이미지

- `alt` 는 **장면을 서술**한다. 제목을 그대로 베끼면 없는 것과 같다
- 사진은 직접 찍은 것으로. 스톡 이미지는 감사에서 걸린다

## 지역 신호

본문 어딘가에 `Mairangi` · `Auckland` · `North Shore` · `New Zealand` 중 하나가 자연스럽게 들어가야
지역 검색에 잡힌다(링크 URL 안의 도메인은 세지 않는다 — 보이는 글자 기준).
