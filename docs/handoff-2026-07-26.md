## 3. 다음에 할 일 (우선순위 순)

### A. 실측 트래픽 분석 — **사용자 액션 대기**
코드 기반으론 개선 소진. 실제 우선순위는 트래픽 데이터 필요.
- **막힌 이유**: GA4(`G-326N3JJFGN`)·Vercel Analytics 모두 자격증명 없이는 이 환경에서 못 읽음. Supabase MCP도 미인증.
- **재개 조건**: 사용자가 `vercel` CLI 로그인(현재 CLI 미설치)하거나, GA4/Vercel 대시보드에서 상위 페이지·이탈률·Core Web Vitals·이벤트 수치를 CSV/스크린샷으로 제공.
- 받으면: 실측 기반으로 개선 재우선순위 → 새 배치.

### B. full `next/font` 이전 — **대형·고위험, 감수 확인 필요**
- **왜 안 했나**: [[project_font_migration_blocked]] 메모리 참조. `@import`만 제거하면 코드 전반 하드코딩 폰트명(`"Playfair Display"`/`"Noto Sans KR"`) **50곳+**가 폴백으로 깨짐. 특히 `components/carousel/slides/*`·`app/mhj-desk/magazines/[id]`·매거진 템플릿은 **html2canvas PNG 렌더** 민감 영역.
- **하려면(전부 아니면 안 함)**:
  1. `app/layout.tsx`에 `Playfair_Display`(가변, style normal+italic)·`Noto_Sans_KR`(weight 400/500/700/900, **`preload:false`** — CJK 필수)·`Caveat`(가변) next/font 선언, `<html className>`에 variable 추가.
  2. `app/globals.css` `@import` 제거 + 모든 `'Playfair Display'`/`'Noto Sans KR'` → `var(--font-playfair)`/`var(--font-noto)`.
  3. **grep으로 전 컴포넌트 하드코딩 폰트명 50곳+ 전수 교체** (`grep -rn "Playfair Display\|Noto Sans KR" app components`). `app/api/og/route.tsx`는 satori(폰트 바이너리 직접 로드)라 별개 — 건드리지 말 것.
  4. **필수 QA**: 매거진 PNG 생성(mhj-desk/magazines/[id]), 캐러셀 슬라이드, MhjBrandReveal, MagazineShelf를 dev+Playwright로 한글 렌더 시각 확인. build만으론 글리프 커버리지 검증 불가.
- 리스크: 한글 폰트 깨지면 사이트 전체 가독성 붕괴. **반드시 감수 확인 후 전용 세션.**
