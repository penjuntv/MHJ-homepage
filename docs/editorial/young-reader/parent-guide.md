# 부모 가이드 (한 장) — 현이의 이달의 책

**원칙: 질문만 하고, 대신 쓰지 않는다.** 현이가 할 일은 워크시트가 다 알려준다. 부모 몫은 아래 네 가지뿐이다.

## 1. 시작할 때 (5분)
- 책 종류에 맞는 PDF 하나를 인쇄한다: `print/worksheet-history.pdf` 같은 식. 종류가 애매하면 `any`
- 포스트잇 3색(노랑·파랑·빨강)을 책과 같이 둔다

## 2. 3일째 끝나고 15분 수다
이 질문 중에서 2~3개만 던진다.
1. "빨간 포스트잇 붙인 데 보여줘. 너라면 어떻게 했을 것 같아?"
2. "②번 네 생각에 아빠가 반대해 볼게." → 짧게 반박하고 현이가 방어하게 둔다. **이기지 말 것**
3. "그 증거, 책 몇 쪽이야?"
4. "키위 친구한테 설명하려면 뭘 먼저 말해줘야 할까?" (영어 칸에 도움이 됨)

## 3. 사진 3장 받기 📷
| 사진 | 언제 | 어디에 쓰나 |
|---|---|---|
| 책 표지 | 1일 | 매거진 사진 칸 |
| 2일째 쪽 전체 | 2일 | Claude가 인포그래픽으로 다시 그림 |
| 4일째 그림 | 4일 | 매거진 사진 칸 |

얼굴이 나온 사진은 쓰지 않는다. 파일 이름에 실명을 넣지 않는다.

## 4. 5일째: 기자 책상
- `writer.html`을 브라우저로 열어 준다. 같은 컴퓨터에서 열면 이어서 쓸 수 있다(자동 저장)
- 빈 칸이 남아 있거나 체크를 안 하면 보내기 버튼이 잠겨 있다. 버튼이 열리면 **복사해서 보내기** → 카톡으로 받는다
- 칭찬은 **"✨ 한 문장 더 좋게"** 칸을 보고 구체적으로 한다

## 하지 말 것
- 주장을 대신 정해주기 → 대신 "다른 생각도 있을까?"
- 종이 단계에서 맞춤법 지적하기. 맞춤법은 편집 단계에서 고친다
- 영어 칸을 한국어의 번역으로 만들기
- 만화나 동화의 각색을 "틀렸다"고 하기 → 대신 "이건 책이 꾸민 걸까?"

## 편집 원칙 (PeNnY)
- 고치는 것: 맞춤법, 띄어쓰기, 사실 오류. 사실 오류는 본문을 바꾸지 않고 **편집자 주**로 단다
- 안 고치는 것: 현이의 어휘, 비유, 문장 길이
- 최종본은 현이가 읽고 "내 글 맞아"라고 해야 발행한다
