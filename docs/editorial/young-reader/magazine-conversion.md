## 1. 지면 구성

| 요소 | 넣는 곳 | 내용 |
|---|---|---|
| 템플릿 | `right` (우측 이미지 3장 + 인포블록) | |
| 사진 칸 ① | 이미지 1 | 책 표지 |
| 사진 칸 ② | 이미지 2 | 현이 그림 (4일째 ⑦) |
| 사진 칸 ③ | 이미지 3 | 책 펼친 장면이나 손으로 쓴 워크시트 (얼굴 X) |

| 인포블록 | `sidebar_title` = `이달의 책 · This Month's Book` | 책 제목 · 지은이 · 출판사 · ★ · 추천 나이 |
| author | `Hyun` · `Min` · `Jin` | 실명 금지 |
| article_status | `draft` → 현이 승인 후 게시 | |

⚠️ **인포그래픽을 사진 칸에 넣지 않는다.** 사진 칸은 `object-fit: cover`로 잘리고 폭도 좁아서 글씨가 읽히지 않는다(`components/magazine/templates/ColumnLayoutTemplate.tsx`). 인포그래픽은 4:3 비율(1600×1200)로 뽑아 본문에 넣는다. 가장 작은 글씨가 30px이라 본문 폭(약 400px)에서도 읽힌다.

## 2. 본문 구조

> **지니 (Level 0)** 는 아래 구조 대신 **문답**이다. 맨 위 인용 = ⑥ 한마디, 본문 = `지니에게 물었어요 · We asked Jin` + Q/A ①~⑤ (말한 그대로, 번역은 `(번역)` 표시), 사진 3칸 = 표지 그림 · 제일 좋은 장면 · 3컷. 짧게 가려면 `Little Notes` 템플릿에 한마디만.

```
> ② 내 생각 한 문장 (한)          ← 풀쿼트
> ② I think … (EN)

[한국어] ①+② / ③ / ④ / ⑤ / **⑥ 질문**
[인포그래픽 이미지 + 캡션 "현이의 취재 노트에서 · From Hyun's notebook"]
---
In English
[English] ①+② / ③ / ④ / ⑤ / **⑥ question**

확인한 자료: … (민이 · Level 2 만)
— 편집자 주: (필요할 때만)
```

기자 책상의 **[복사해서 보내기]** 결과는 이미 이 순서로 문단이 나뉘어 있다.

## 3. Claude 프롬프트 (복붙용)

```
docs/editorial/young-reader/magazine-conversion.md 대로 현이의 이달의 책 기사를 만들어줘.
1) 원고: 아래 붙여넣은 기자 책상 텍스트
2) 2일째 쪽 사진: [첨부] → infographics/<YYYY-MM>/<종류>.json 을 만들고
   render.mjs infographic 으로 PNG 생성. 현이가 쓴 내용만, 말투 그대로, 칸이 비면 비워 둘 것
3) 현이 문장은 맞춤법·띄어쓰기만 고치고, 고친 곳은 목록으로 따로 보여줘
4) 역사·고사성어 사실은 fact-verify 로 확인. 틀린 건 본문 대신 편집자 주 초안으로
5) 실명·학교·친구 이름이 있으면 멈추고 알려줘
결과: title / 본문 HTML / sidebar_title / sidebar_body / 인포그래픽 PNG 경로 / 이미지 캡션

[기자 책상 텍스트 붙여넣기]
```

인포그래픽 JSON 형식은 `infographics/examples/*.json`을 그대로 따른다. 민이 원고면 `"kid": "min"`을 넣는다(머리글·꼬리말 이름이 바뀜).

| 2일째 쪽 | `type` |
|---|---|
| 역사 | `timeline` |
| 이야기·고사성어 | `story4` |
| 지리 | `map` (`"image": "현이지도.jpg"` 경로를 넣으면 현이가 그린 지도가 들어감) |
| 문화 | `compare` |
| 사회 | `flow` |
| 어떤 책이든 | `facts3` |
