HYUN'S MONTHLY BOOK유씨 가이드 2/2 · 매거진에 올리기

카톡으로 받은 글 → 매거진 기사

받은 글은 이미 문단 순서대로 정리되어 있습니다. 맞춤법만 고쳐서 칸에 붙여 넣으면 됩니다. 약 20분.

1mhj-desk에서 기사 만들기

  1. mhj-desk → 매거진 → 이번 호 열기 → ✍️ 기사 편집 탭 → + 새 기사
  2. 상태: 초안  ·  템플릿: 메인 기사 → Right (우측 이미지 3장)
  3. 제목 *: 한국어 제목 · English Title (받은 글의 "제목(한)"과 "Title(EN)")
  4. 저자: Hyun만 선택  ·  날짜: 발행일
  5. 사진 3칸: ① 책 표지 ② 현이 그림 ③ 책 펼친 장면 (얼굴 없는 사진). 잘리면 9칸 위치 버튼으로 조정
  6. 인포블록 콘텐츠 → Sidebar Title: 이달의 책 · This Month's Book / Sidebar Body: 받은 글 둘째·셋째 줄 (책 제목·지은이·출판사·★·추천 나이)
  7. 텍스트 본문 칸을 열고 아래 순서로 붙여 넣기 ↓
본문 순서
  1. ② 내 생각 한 문장 (한/EN): 인용으로 맨 위에
  2. ── 한국어 글 ── 전체
  3. 인포그래픽 그림 (PeNnY에게 받은 PNG, 있을 때만)
  4. 구분선, 그다음 소제목 In English
  5. ── English ── 전체
  6. 마지막 질문 문장은 굵게
고치는 것 / 안 고치는 것
  • ✔ 맞춤법, 띄어쓰기
  • ✔ 사실이 틀리면 본문은 두고 끝에 — 편집자 주: …
  • ✘ 현이의 단어, 비유, 문장 길이
  • ✘ 영어를 한국어에 맞춰 바꾸기

받은 글 맨 아래 "칸별 원본"은 참고용입니다. 붙여 넣지 마세요.

2확인하고 발행

  1. 기사 추가(저장) → 🔍 전체 미리보기 탭에서 넘친 곳이 없는지 확인. 넘치면 영어 글을 줄이지 말고 PeNnY에게 알려 주세요
  2. 현이에게 미리보기를 보여주고 "내 글 맞아?" 승인 받기
  3. 상태를 발행됨으로 바꾸고 저장 → 호도 발행 상태인지 확인
