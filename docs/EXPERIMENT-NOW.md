## 3-3. 뒤집힌 가정 두 가지 (같은 회신)

**① 학년 배정 질문은 학부모 수요가 아니다.** 유씨가 받은 "학년 배정 기준" 질문은 **미혼 친구들의 스몰톡**이었다. NZ 에 이미 사는 학부모는 그걸 이미 안다.
→ `PLAN-distribution` §3 자산 **#3 학년 대조표**의 수요 가정이 무너졌다. 보류를 넘어 **후보에서 내린다.**
→ 대신 실물 수요가 확인된 두 곳: **막 도착하는/아이를 데려오는 가정**(§3-2) · **성적표를 받아 든 부모**(GSC `consolidating` 94노출, `docs/measurements/gsc-2026-09-23.md`).

**② 페이스북 프로필은 친구가 0명이다.** "미확인"으로 남겨 뒀던 숫자가 **0**으로 확인됐다.
→ 실험 1b 의 페북 트랙은 **도달이 구조적으로 0**이다. 게시해도 아무에게도 안 보인다.
→ 자체 채널 실사용 도달: 유튜브 115(링크 자리 없음) · 인스타 13 · 페북 **0** · 뉴스레터 16. **자체 채널은 지금 경로가 아니다.**

**그래서 다음 주의 중심은 1:1 이다.** 유씨가 같은 방식으로 **2~3명 더** 보내는 것 — 그게 유일하게 작동이 확인된 경로다.

## 3-4. 실험 1 의 천장 — 그래서 중심이 검색으로 옮겨간다 (2026-09-23)

유씨가 **"우리 홈페이지를 소개할 만큼 친한 친구는 더 없다"** 고 알렸다.

→ **작동이 확인된 유일한 경로에 천장이 있다.** 1:1 전달은 1~2명에서 끝나고, "다음 주 2~3명 더"는 실행할 대상이 없다.
→ 자체 채널도 막혀 있다(페북 0 · 인스타 13 · 유튜브는 링크 자리 없음, §3-3).
→ **남는 것은 검색뿐이고, 마침 검색에는 다룰 재료가 있다** — 3개월 노출 2,320 · 클릭 25. 순위가 아니라 **클릭률**이 막힌 자리다(`measurements/gsc-2026-09-23.md`).

**중심을 옮긴다: 1:1 → 검색 클릭률.** 1:1 은 기회가 생기면 계속하되 계획의 축으로 삼지 않는다.

이 판단의 근거는 하나다 — **노출은 이미 있다.** 새 독자를 데려올 새 통로를 찾는 것보다, 이미 우리를 보고 있는 2,320회에서 클릭을 만드는 편이 확률이 높다.

### 그래서 무엇이 달라지나
