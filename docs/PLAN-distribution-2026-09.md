# 배포·바이럴 플랜 (2026-09-19 ~)

> `docs/PLAN-search-visibility-2026-09.md` 는 **끌어오기(pull)** 플랜이다 — 검색엔진·AI 가 찾아오게 하는 구조.
> 이 문서는 거기에 없던 절반, **밀어내기(push)** 다 — 글을 사람이 있는 곳으로 가져가는 일.
> 이 문서의 모든 항목은 한 질문으로 거른다: **"이 일이 끝나면 mhj.nz 에 새 사람이 도착하는가?"**
>
> ⚠️⚠️ **최신 기준은 `docs/PLAN-exposure-root-fix-2026-09-20.md` v2.** 아래 경고의 "1순위 독자 = 이민자 부모" 도 v2 에서 가설로 강등됐다. §0 의 "direct = 가족·QA" 해석도 근거 없음(v2 §1).
>
> ⚠️ **2026-09-20 — §1~§3 은 시장 조사 전에 쓴 가설이다.** `docs/research/market-reality-2026-09-20.md` 가 뒤집은 것:
> 교민 매체 기고 철회(NZ 한인 시장 전체가 하루 6천 명) · 1순위 독자는 한인이 아니라 **영어로 찾는 이민자 부모**(연 순유입 5만 8천) ·
> 인스타보다 **페이스북 그룹**(NZ 보급률 89%) · 학년 대조표는 BoundFor 계산기가 선점 — 각을 바꿀 것.
> 채널·자산은 유씨 답변(`docs/ask-yussi-2026-09-20.md`)을 받은 뒤 다시 쓴다. §0 실측과 §5 측정(UTM)만 그대로 유효.

## 0. 실측 — 왜 이 문서가 필요한가

`page_events` 전체(2026-09-02 ~ 09-19, 17일):

| 지표 | 값 |
|---|---|
| 세션 합계 | 93 |
| direct(대부분 가족·QA) + internal | 88 |
| organic (google 2 · bing 2 · duckduckgo 1) | **5** |
| **social** | **0** |
| **referral** (다른 사이트의 링크) | **0** |
| 공유 버튼 클릭(`blog_share`) · 인스타 팔로우 클릭 | **0 · 0** |
| UTM 달린 착지 | 0 |
| 구독자 | 15 (변동 없음) |

읽는 법: 검색이 약한 게 아니라 **유입 경로 자체가 없다**. 17일 동안 바깥 세계에서 mhj.nz 로 들어오는 링크를 밟은 사람이 0명이다.
인스타(@mhj_nz)·페이스북 페이지·유튜브(@mhj_nz)·뉴스레터가 이미 있는데도 0 이라는 건, 그 채널들이 사이트로 사람을 보내는 **절차**가 없다는 뜻이다.

같은 기간 한 일: seo_title·한국어 요약·FAQ 39/82편 보강. 색인·외부 신호가 없는 도메인에서 온페이지 보강의 한계 효용은 0 에 가깝다 — 글이 나빠서가 아니라 **아무도 그 글 앞에 서 본 적이 없어서** 유입이 없다.

**결론**: 8주 목표(주간 유기 60·구독 30)는 pull 만으로는 오지 않는다. push 가 먼저 돌아야 pull 도 붙는다(방문·공유·링크가 검색 신호다).

## 1. 독자는 어디에 있나

| 군 | 누구 | 언어 | 있는 곳(후보 — ⚠️ 두 분이 실제 가입·규칙 확인 필요) | 이들이 원하는 것 |
|---|---|---|---|---|
| **A** | 한국에서 NZ 조기유학·이민·1년살기를 **알아보는** 부모 | 한국어 | 네이버 검색·블로그·카페, 유튜브, 인스타 | "진짜 겪은 집"의 구체 정보 — 학년 배정, 입학 절차, 성적표, 생활비, 동네 |
| **B** | NZ 에 **사는** 한인 부모 | 한국어 | 코리아포스트 등 교민 매체, 카톡 오픈채팅·학부모방, 교민 페이스북 그룹 | 방학 일정·행사·도서관·학교 제도 변화(NCEA) |

## 2. 채널 — 세 겹

**① 내 채널(이미 있음, 절차만 없음)**
- 인스타 @mhj_nz — 글마다 카드 1세트. `/mhj-desk` 캐러셀 도구가 이미 있다. 프로필 링크 = 최신 글 또는 링크 모음 페이지
- 페이스북 페이지 minhyunjin.nz — 글 링크 + 2문장. 지역 그룹 공유의 발판
- 뉴스레터 Mairangi Notes — 15명. 모든 배포물의 최종 CTA 는 "구독"
- 유튜브 @mhj_nz — 당장은 설명란·커뮤니티 탭 링크만

**② 빌린 채널(새로 열 것)**
- **네이버 블로그** — 주 1편, `summary_ko` + 사진 2~3장 + "전문은 mhj.nz" 링크. A 군으로 가는 유일한 현실 경로. 마스터 플랜에 "선택"으로 있던 것을 **필수**로 올린다
- **Pinterest** — 체크리스트·대조표·홈러닝 아이디어는 핀 수명이 길다(수개월~수년). C 군 + 영어권 홈스쿨 독자

**③ 남의 채널(가장 세고 가장 느림)**
- 교민 매체 기고·칼럼 — PeNnY 의 기자 경력이 그대로 통하는 곳. 기고 1편 = 백링크 + B 군 도달
- 커뮤니티 — **링크 뿌리기 금지.** 질문에 답을 쓰고, 근거로 글을 건다. 주 2회면 충분
- 글에 등장한 기관 — 도서관·학교·축제 주최 측에 "소개했습니다" 한 줄. 그들이 공유하면 로컬 백링크

## 3. 공유될 글 — "저장·전달할 이유"가 있는 자산 5편

지금 82편은 대부분 에세이다. 에세이는 브랜드를 만들지만 **퍼지지 않는다**. 실제로 검색이 찾아온 글은 전부 정보형이었다(starting-school · NCEA · mid-year report · IKEA).
에세이를 그만 쓰자는 게 아니다 — **정보형 자산이 사람을 데려오고, 에세이가 그 사람을 남게 한다.**

| # | 자산 | 형태 | 왜 퍼지나 | 기반 글 |
|---|---|---|---|---|
| 1 | **한국 학년 ↔ NZ Year 대조표** (생일 기준 배정 포함) | 한/영 표 + 저장용 이미지 카드 | A 군이 가장 먼저 묻는 질문. 카페·카톡에서 이미지째 돈다 | starting-school (허브) |
| 2 | **NZ 입학 첫 주 체크리스트** | 본문 + PDF(구독 시 발송 = 리드 마그넷) | 저장형. 구독 15 → 30 의 직접 장치 | starting-school · 100-days |
| 3 | **NZ 성적표 읽는 법** 확장판 | 용어 풀이표 + 실제 예시 | 이미 구글 5위 — 1위권으로 올릴 유일한 글 | how-to-read-a-mid-year-report |
| 4 | **North Shore 도서관 가이드** 허브 | 3편 → 허브 1편 + 비교표 | 로컬 검색·지역 그룹 공유. 도서관 측 공유 가능 | library-tour 3편 |
| 5 | **텀 방학 캘린더 + 방학에 한 것들** | 매 텀 갱신하는 상록 글 | 연 4회 반복 수요. B·C 군 모두 | quiet-week · reading-bingo · fairy-festival |

제작 분담은 기존 원칙 그대로: 구성·표·사실 확인·카드 문안 초안 = Claude, 본문 목소리·승인 = 두 분.

## 5. 측정 — 구멍부터 막는다

- **UTM 미인식(코드 결함, 이 플랜의 유일한 선행 코드 작업)**: `lib/traffic-source.ts` 는 referrer 만 본다. 인스타·카톡 인앱 브라우저는 referrer 를 지운다 → 소셜 유입이 전부 `direct` 로 찍혀 QA 세션과 섞인다. `utm_source`/`utm_medium` 을 읽어 source·medium 을 덮어써야 배포 효과가 보인다. **이걸 안 고치면 아래 지표를 잴 수 없다.**
- 주간 지표는 넷뿐: ① 외부 유입 세션(organic + social + referral) ② 채널별 세션 ③ 구독자 ④ 공유 클릭. `report-traffic-snapshot.mjs` 에 social·referral 열 추가
- **성과 지표가 아닌 것**: 운영 컬럼 채움 수(n/82) · 감사 통과 수 · 머지된 PR 수

4주 목표(10/17): 외부 유입 주 30 · 구독 22 · 채널 3개 이상에서 유입 확인. 8주(11/14): 주 80 · 구독 35.
(근거가 약한 방향 목표다 — 2주 뒤 실측으로 다시 잡는다.)
