# 노출 문제 근원 해결 기획안 — v2 (2026-09-20)

> v1(같은 날)에 대한 검토를 반영해 고쳤다. v1 에서 **근거보다 앞서 나간 판단 셋**을 거둬들였다:
> "신규 방문 0명" · "한인 시장은 너무 작다" · "자동화가 먼저다".
> 유지한 핵심은 하나 — **새 글 없이 기존 글을 실제 독자 앞에 놓아 본다.** 다음 주는 이 실험이 중심이다.

---

## 1. 지금 확실히 말할 수 있는 것과 없는 것

**확실한 것** (page_events, 09-02 ~ 09-20, pageview 세션 94)
- 검색 유입으로 분류된 세션 **5** (bing 2 · google 2 · duckduckgo 1 — 4건 NZ, 1건 US, 전부 데스크톱·1페이지)
- SNS·추천·이메일로 분류된 세션 **0** · 공유 버튼 클릭 0 · 구독자 15(변동 없음)
- 수집 코드에 **운영자·테스트 방문을 가르는 장치가 없다**(`app/api/track`·`lib/first-party.ts`, PR #100 포함)

**확정할 수 없는 것**
- direct 82 세션이 누구인가. v1 은 "가족·QA"로 단정했지만 근거가 없다. 국가별로 NZ 51 · **KR 12 · US 10** · SG 3 · GB 2 · 미상 4, 1페이지 이탈 58 — 운영자 점검과 외부 독자가 섞여 있고, 현재 자료로는 가를 수 없다. direct 는 "출처가 안 남은 방문"이지 "내부 방문"이 아니다([Google](https://support.google.com/analytics/answer/15258820?hl=en)).
- 검색 5세션이 외부 독자인지 운영자 점검인지.
- 09-17~19 보강(39편)의 검색 효과. 사흘은 판정하기에 짧다 — 구글은 변경 효과를 보려면 보통 몇 주 걸린다고 안내한다([Google](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)).

**그래서 첫 문장은 이렇다**:
> 작업량에 비해 외부 독자 확보 성과를 확인하지 못했고, 현재 측정만으로는 신규 독자 수를 확정할 수 없다.

## 2. 근원 — v1 에서 고친 것

| # | 근원 | v1 → v2 |
|---|---|---|
| R1 | 진척을 "끝낸 일"로 보고했다(운영 컬럼 n/82, PR 머지 수) | 유지 |
| R2 | 독자 쪽 신호(실제 질문·검색 노출)를 보지 않고 공급을 만들었다 | "수요 데이터가 없다" → **"독자 신호를 한 번도 확인하지 않았다"**. GSC 는 이미 노출된 영역만 보여 주므로 수요의 일부일 뿐이다 |
| R3 | 사람만 할 수 있는 일(배포·콘솔·결정)을 굴리는 방식이 없었다 | 유지 |
| R4 | ~~포지셔닝이 시장과 어긋난다~~ | **철회 → 가설로 강등.** "한인 시장은 작다"는 순유입 통계를 학부모 수로 바꿔 읽은 오류 위에 서 있었다(§5). 주 20세션 단계에서는 작은 시장도 충분하다 — 중요한 건 닿을 수 있는지, 신뢰가 있는지, 실제 질문이 있는지 |
| R5 | 여러 세션이 동시에 돌며 범위가 새어 나간다 | 유지. 단 v1 의 해법(보여 주기만 하는 hook)은 강제가 아니다 → §4 에서 운영 방식으로 바꿈 |
| R6 | **측정이 배포를 판정할 수 없다** (신설) | 운영자 제외 없음 · UTM 은 PR #100 이 열렸지만 실제 배포 링크로 확인 전 |

## 3. 지표 — 둘을 유지하되 정의를 좁힌다

| 지표 | 정의 |
|---|---|
| **외부 유입 세션/주** | 출처가 식별되는 외부 세션(검색·SNS·추천·이메일), **운영자·테스트 제외**. 이메일은 기존 구독자 재방문일 수 있어 따로 적는다 |
| **구독자** | 총수 + **주간 순증**(확인 완료 기준이 가능하면 그것으로) |

**실험 기록**(성과 보고와 별개, 실패 원인을 가리기 위해): 게시 위치·시각 · 게시물 도달 수(보이면) · 링크 유입(UTM) · 구체적 반응(댓글·질문·DM) · 든 시간.

| 관찰 | 다음 판단 |
|---|---|
| 게시물이 거의 안 보였다 | 장소·방법 |
| 보였는데 클릭이 없다 | 주제·소개 문구·대상 적합성 |
| 왔는데 후속 반응이 없다 | 글의 유용성·구독 이유 |
| 적은 방문에서 구체적 질문·구독이 나왔다 | 같은 조건으로 반복 |

"주 20" 은 방향 목표다. 실패 판정 기준으로 쓰지 않는다 — 방문 20건·구독 0건은 표본이 작아 아무것도 배제하지 못한다.

## 4. 운영 방식 — 동시에 하나의 실험

- **현재 실험 1개 · 담당자 · 종료 조건**을 한 곳(`docs/EXPERIMENT-NOW.md`)에 둔다. 새 일을 시작하는 세션은 먼저 이걸 읽고, 새 일이 현재 실험보다 앞서는지 한 줄로 적는다. 이게 범위 관리의 본체다.
- 세션 시작 알림 hook 은 **보조 장치**로만(현재 실험·지표 표시). 강제라고 부르지 않는다. 실험을 늦추지 않는 범위에서 나중에.
- 사람 몫은 `EXPERIMENT-NOW.md` 안에 담당·기한과 함께 적는다(별도 원장 파일은 만들지 않는다).

## 5. 시장 조사에서 바로잡을 것

- **58,700 은 비시민권자 순유입**(입국 − 출국)이다. 학부모 수도, 자녀 동반 가구 수도 아니다. v1·질문지에서 "아이를 데리고 이주하는 외국인"으로 바뀌어 쓰였다 — 오류. 수치 자체도 이번 세션에서 Stats NZ 원문 본문을 읽지 못해 **미검증**이다.
- 한인 거주 인구(저량)와 연간 순유입(유량)을 나란히 놓고 "10배"라고 한 것 — 철회.
- "한인 전체를 잡아도 주 수백이 한계" · "코리아포스트 일일 방문 = 한인 시장 천장" — 근거 없음, 철회.
- "실거주 부모의 글이 검색 결과에 없다" — 몇 개 검색어의 첫 결과만 본 관찰이다. 단정 철회, 관찰로 남김.

→ `docs/research/market-reality-2026-09-20.md` 에 반영.

**독자 가설(시험 대상)**:
> NZ 초등학교 입학이나 첫 성적표를 앞두고, 공식 안내를 실제 생활에 적용하기 어려운 부모.

국적으로 가르지 않고 **상황과 문제**로 좁힌다. 영어 글로 닿는지 보되, 한국어권 연결망도 초기 통로로 쓴다. 장소 두 곳의 반응 차이만으로 국적별 선호를 결론 내지 않는다(장소마다 신뢰·도달 조건이 다르다).

## 6. 순서

| 시점 | 할 일 | 누가 | 얻어야 할 증거 |
|---|---|---|---|
| **1~2일** | ① 측정 확인(아래 완료 기준) ② 유씨와 짧은 대화 — 질문 4개(`docs/ask-yussi-2026-09-20.md`) | Claude · PeNnY→유씨 | 셀 수 있는 유입 · 실행 가능한 공유 장소 1곳 이상 |
| **1주** | 유씨가 받은 실제 질문에 맞는 **기존 글 1편**을 허용된 곳 1곳에 소개(UTM 링크, Claude 가 소개 문안 초안) | 유씨 | 독자가 실제로 도착하는가 |
| **2주** | 같은 글의 다른 소개 방식, 또는 두 번째 장소 | 유씨 | 무엇을 바꾸면 반응이 달라지는가 |
| **3~4주** | 반응이 있었던 질문을 보강하거나 글 1편 | 유씨 집필 · Claude 구성·사실 확인 | 반복되는 방문·질문·구독 신호 |

**측정 완료 기준**(PR 번호가 아니라 동작으로):
1. UTM 테스트 링크가 의도한 source·medium 으로 기록된다
2. 사이트 안 이동이 세션을 중복으로 세지 않는다
3. 운영자·테스트 방문을 제외할 수 있다 — **현재 없음.** 가장 작은 방법(예: 운영자 기기에 제외 표시를 남기는 1회성 링크)을 PR #100 에 더하거나 별도 PR 로

**병행(실험을 늦추지 않는 범위)**
- GSC: 첫 실험에는 **한 번의 수동 내보내기**(검색어·페이지, 최근 3개월)면 충분하다. 서비스 계정 자동화는 프로젝트·인증·권한·실행 환경까지 필요한 일이라 "5분"이 아니다 — 실험과 나란히, 서두르지 않는다. GSC 는 이미 노출된 영역만 보이고 일부 검색어는 빠진다([Google](https://developers.google.com/search/blog/2022/10/performance-data-deep-dive)) — **노출 수를 검색량으로 읽지 않는다.**
- 다음 글 주제는 세 근거를 겹쳐 고른다: GSC 에 보이는 기존 기회 · 부모들이 반복해서 묻는 질문 · 유씨가 경험으로 구체적으로 답할 수 있는 것.
- Bing API · 세션 알림 hook: 첫 실험 뒤.

## 7. 멈추는 것 — 이유를 바로 적는다

- 남은 일괄 보강 — **효과가 없다고 증명돼서가 아니라**, 시간을 배포 실험에 돌리기 위해. 보강한 39편의 검색 효과는 4~6주 뒤(10월 말) GSC 로 따로 본다.

- 확인 안 된 도구로 사용자 브라우저·계정에 접근하는 것.
