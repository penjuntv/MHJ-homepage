② 두 분이 하실 일 (후속 액션)

코드는 다 끝났습니다. 아래 두 가지는 "내용 채우기"라 제가 대신 할 수 없는, PeNnY·Yussi 손이 필요한 일입니다.

PeNnY 또는 Yussi 갤러리 사진에 "누가 찍었는지" 지정

  1. 관리자 페이지 접속 → www.mhj.nz/mhj-desk → 왼쪽 메뉴 Gallery
  2. 올라온 사진 7장을 하나씩 열어, 촬영자(Photographer)를 Min / Hyun / Jin / PeNnY / Yussi 중에서 고르기
  3. 저장하면 끝 — 그 즉시 갤러리 필터가 살아납니다

왜? 사진에 촬영자 정보가 비어 있어 지금은 필터를 눌러도 빈 화면이 뜹니다. 누가 찍었는지는 두 분만 아시니까요.

Yussi (엄마) 딸에게 보내는 편지 1편 발행

  1. 관리자 → 블로그 새 글 작성
  2. 편지 옵션에서 받는 사람(M=민 / H=현 / J=진) 지정하고 글쓰기
  3. 발행하면 → 홈 화면 매거진 위에 "A Letter Home" 섹션이 자동으로 나타납니다

왜? 섹션 기능은 완성됐지만 아직 편지 글이 0개라 숨어 있습니다. 첫 편지를 쓰는 순간 켜집니다.
