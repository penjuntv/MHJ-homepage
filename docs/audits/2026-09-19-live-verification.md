## 4. 고치는 순서 (각각 별도 대화 · Plan Mode → 승인 → 구현 · CLAUDE.md 12)

1. **매거진 이미지 최적화** — `components/magazine/ArticlePageRenderer.tsx`(지면 템플릿)·`PageThumbnail` 이 Supabase 원본 `<img>` 를 쓰고 슬롯 이미지를 전부 `preload` 한다. 공개 렌더 경로만 `nextImageUrl`/반응형 srcset 로 돌리고 preload 는 첫 화면 1장만. **지면 렌더(PNG 파이프라인·620×812 고정 캔버스)의 픽셀이 바뀌지 않는지 디프로 증명**(`docs/MHJ_MAGAZINE_DESIGN_BIBLE.md` 관할). 기대: 7월호 47MB → 수 MB, 3월호 모바일 LCP 13.9s → 3s 대.
2. **빈 호 처리** — 5월·8월호를 (a) 내용이 채워질 때까지 서가·sitemap 에서 내리거나(`published=false`) (b) 유지하되 `noindex` + "LATEST" 는 내용 있는 최신 호에 붙이기. **편집 결정 필요.**
3. **갤러리 라이트박스** — `role="dialog"` · `aria-modal="true"` · `aria-label` · 열릴 때 포커스 이동/닫힐 때 복귀 · 화면 밖 사진 지연 로드 확인.
4. **모바일 리더 CLS** — `.mv-page-wrap` / `.mv-mobile-bottom` 높이 예약.
5. **보안 헤더** — `next.config` `headers()` 로 nosniff · Referrer-Policy · Permissions-Policy · frame-ancestors. CSP 는 GA·Vercel·Supabase·Instagram 허용 목록이 필요해 Report-Only 로 먼저. 루트 도메인 308 은 Vercel 대시보드(사용자).
6. **PDF 뷰어 라벨 영어화** — 기능 영향 없음, 마지막.

## 5. 재발 방지

- 새 점검 `scripts/qa/live-functional-check.mjs` 는 "최적화 안 된 300KB 초과 원본 이미지" · "발행된 빈 호" · "대화상자 표시 없는 라이트박스" 를 결함으로 센다. **1·2·3 번이 고쳐진 뒤** 주간 site-audit ⑮ 로 편입한다(지금 편입하면 매주 빨간불이 켜져 경고가 벽지가 된다 — 매거진 넘침 경고의 전례).
- 오탐 두 가지는 스크립트에 박아 두었다: 문서 자체의 404 를 하위 요청 실패로 세지 않는다 · `/api/*` 는 쓰기만 가로챈다(GET 까지 막으면 가짜 JSON 오류).
