## 4. 구역

| 요소 | 바뀌는 것 |
|---|---|
| 선반(768 이상) | 책등 줄 끝(오른쪽)에 **최신 호 표지를 세워 진열**(서점의 face-out). 표지는 42:55 원래 비율 그대로 336×440px(책 높이와 같음) — 자르지 않는다. 링크·`magazine_open` 기록은 책등과 같다 |
| 책등 | 펼침 동작 그대로. "Latest" 배지는 세운 표지로 옮긴다(같은 호에 두 번 붙지 않게) |
| 안내 문구 | 마우스가 있는 768 이상에서만 보인다(모바일 카드·태블릿 터치엔 맞지 않는 말). 문구는 DB 값 — "Hover a spine to see the cover" 로 바꾸는 것은 승인 후 |
