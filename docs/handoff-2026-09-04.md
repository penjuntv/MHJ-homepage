## 2. ✅ 완료 — seo-audit-runner 스킬의 GEO 오탐 구조 정비 (PR #39)

`SKILL.md` 의 SQL 을 `scripts/audit-seo-regression.mjs` 기준으로 동기화했다.
착수 후 **알려지지 않았던 두 번째 오류**를 하나 더 찾았다:

1. **GEO 오탐**(§2 가 지목한 것) — 원문 HTML 에서 키워드를 찾아 `href="...mhj.nz..."` 의
   `nz` 가 지역 신호로 집계됐다. 보이는 텍스트 기준으로 고쳐 **no_geo 4 → 22편**.
   ⚠️ 이 오탐은 내부링크를 늘릴수록 커진다 — ORPHAN 정비가 GEO 개선처럼 보인다.
   **2026-09-04 이전 보고서의 GEO 수치와는 비교 금지.**
2. **Postgres `\b` 는 단어 경계가 아니다**(백스페이스다 — 단어 경계는 `\y`).
   옛 SQL 의 `'<h2\b'` 가 아무것도 매치하지 않아 **h1/h2 카운트가 항상 0** 이었다.
   `\y` 로 고친 실측: H2 0개인 글 11편, no_h2(400단어+ & H2<2) 6편.
   초기 서술 "52편 전부 H2 0개"는 이 버그의 산물일 수 있으니 근거로 쓰지 말 것.
   `.mjs` 는 JS 정규식이라 `\b` 가 맞고 정상이었다.

**실측 대조표 (2026-09-04, 발행 79편)** — 두 경로가 이 값에서 일치해야 한다:
THIN 36 · ORPHAN 10 · NO_GEO 22 · ALT 누락 3 · NO_H2 6 · H1 혼입 0 · meta 누락 0.
(ALT 는 인포블록 포함 3편, 본문만 세면 2편.)

**앞으로**: 판정 로직은 `SKILL.md` 의 SQL 과 `audit-seo-regression.mjs` 가 **한 쌍**이다.
한쪽만 고치면 주간 게이트와 분기 보고서가 다른 답을 낸다 — 양쪽 상단에 상호 참조를 박아 뒀다.

## 6. 지뢰밭 — 이 프로젝트에서 실제로 밟았던 것들

1. **워크플로 run 블록**: 이슈 본문은 반드시 quoted heredoc (#32 사고). run 블록 안에는
   **주석에라도** 빈 `${{ }}` 표현식 금지 — 파싱 422 (#33 사고).
2. **락파일은 npm@10 기준**: 로컬 npm@11 은 결손 락도 통과시킨다. CI 재현은
   `npx npm@10 ci --dry-run` (#29 사고).
3. **Supabase API**: `listUsers()` 는 MFA factors 를 안 채운다(전원 0 으로 보임) —
   `admin.mfa.listFactors({userId})` 가 권위. 이걸 믿고 계정을 지웠다 복구한 사고 있음.
   존재하지 않는 컬럼 select 시 **쿼리 전체가 조용히 null** — `data ?? []` 로 삼키면
   테이블 통째 누락 (감사 스크립트 og_image 사고). RPC 인자명은 `days`/`lim`.
4. **매거진**: 템플릿에 `cqh`/`vh` 금지 (mag-unit-guard 훅이 차단, 사유는
   `docs/MHJ_MAGAZINE_DESIGN_BIBLE.md` §cqh). 세로 비율은 `calc(N * var(--mag-cqh))`.
   리딩 뷰어 검증 URL 에 **`?page=1` 필수** — 없으면 이슈 상세(썸네일)가 열려 오판.
   `?page=N(≥3)` 은 슬러그 URL 로 308 리다이렉트된다.
5. **감사 로직**: 텍스트 매칭은 반드시 case-insensitive (i 플래그 누락 → NO_GEO 32 오탐
   사고). **HTML 을 대상으로 키워드를 세지 말 것** — 마크업 속 URL(`mhj.nz`)이 본문
   키워드로 잡힌다(§2). **Postgres 정규식의 단어 경계는 `\y`** — `\b` 는 백스페이스라
   `'<h2\b'` 가 조용히 0을 돌려준다(JS 는 `\b` 가 맞다). 두 오류 다 "결과가 0/정상으로
   보이는" 위음성이라 눈에 안 띈다 — **감사 스크립트는 위반을 주입해 exit 1 을 실증할 것.**
   실명 패턴은 name-guard 훅에 걸리므로 **코드포인트 인코딩**으로 다룬다
   (`audit-name-exposure.mjs` 방식). public repo CI 로그에 실명 원문 출력 금지 — [라벨] 치환.
6. **이미지**: 공개 페이지 `<img>` 는 원본 직결 금지 — `lib/image-url.ts` 경유.
   width 는 next.config 의 128/256/384/640/1080/1920 만 유효(그 외 400).
7. **훅 5종 가동 중**: safety-gate(Bash: git add -A·force push 등 차단) ·
   scope-guard · name-guard · mag-unit-guard · select-star-guard (Edit/Write/MultiEdit).
   차단되면 우회하지 말고 원인 해소 — 예: rebase 후 force push 가 safety-gate 에 막히면
   `--no-verify` 를 찾지 말고 새 브랜치로 PR 을 다시 여는 쪽이 맞다(2026-09-04 실사례).
8. **여러 세션이 같은 작업을 병행한다**: 2026-09-04 에 이 가드 작업을 두 세션이 동시에
   진행해 #36 과 #37 이 겹쳤다(#37 닫고 #38 로 재정리). 착수 전 `gh pr list` ·
   `git fetch origin main` · `gh run list` 로 **원격 상태를 먼저 확인**할 것 —
   로컬 main 이 최신이라는 보장이 없다.
