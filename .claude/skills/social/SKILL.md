# 소셜 — 도달이 0에 가까운 채널을 정직하게 쓰기

> 거르는 질문: **"이 게시물이 끝나면 mhj.nz 에 새 사람이 도착하는가?"**
> 게시 횟수·좋아요는 성과가 아니다.

원본의 중심 문장은 MHJ 에도 그대로 맞다: **플랫폼 요령은 좋은 이야기를 키워 줄 뿐, 대신하지 못한다.**
MHJ 의 이야기는 "세 딸과 마이랑이 베이에서 사는 한 가족이 직접 겪은 것"이다.

## 먼저 숫자 — 자체 채널은 지금 경로가 아니다

| 채널 | 크기 | 실측 결과 (2026-09-21 ~ 10-22) |
|---|---|---|
| 유튜브 @mhj_nz | 구독자 117 · 영상 296 | 커뮤니티 탭 없음. 설명란 링크 `/yt` 세션 대부분이 자동 점검 방문 |
| 인스타 @mhj_nz | 팔로워 13 | 게시물+스토리 링크를 정상으로 올렸는데 6세션 전부 체류 5초 미만 |
| 페이스북 `minhyunjin.nz` | 개인 프로필, **친구 0** | 도달이 구조적으로 0 → **중단** |
| 스레드 | — | **n=1 신호**: 예전 글에서 한국 태블릿 1세션, 29초, 2페이지 |
| 뉴스레터 | 16명 | 모든 게시물의 최종 목적지 |

소셜 22세션 중 두 페이지 이상 본 세션은 **스레드 1건뿐**이다 (`docs/EXPERIMENT-NOW.md` §3-5).
작동이 확인된 경로는 소셜이 아니라 **사람이 사람에게 보내는 것**이다 → **referrals** 스킬.

그래서 이 스킬은 "매일 올리기"를 권하지 않는다. **이미 사람이 있는 곳부터, 넘겨지기 쉬운 형태로** 만든다.

## 우선순위

1. **유튜브 — 사람이 이미 있는 곳.** 117명 + 영상 검색.
   - 새 영상을 올릴 때 **설명란 첫 줄**에 관련 글 링크. 채널 고정 자리에는 `https://www.mhj.nz/yt`.
   - **쇼츠**: 블로그 정보형 글의 답 하나를 30~60초로. 제목은 사람들이 실제로 치는 질문으로.
   - 영상을 위해 새 촬영을 기획하지 않는다. 이미 있는 장면·사진·글에서 뽑는다.
2. **넘겨지는 콘텐츠 — 카톡·WhatsApp 단톡방으로 흘러가는 카드.**
   - 유씨의 연결망은 대면·영어권·개인 관계가 중심이고 카톡 단톡방은 적다(referrals "시작 전에 확인할 것" 4번). 그래서 **영어 WhatsApp 판을 기본으로 함께** 만든다.
   - 한 장짜리 요약 이미지(답 3~4줄 + `mhj.nz` 주소) 또는 짧은 텍스트 + 링크.
   - 이미지 속 `mhj.nz` 는 **홈**으로 간다. 이미지만 돌면 글을 못 찾는다 → 카드는 **언제나 UTM 글 링크가 든 문안 메시지와 짝으로** 보낸다.
   - 목표는 "우리 채널 팔로워"가 아니라 **누군가 단톡방에 이 카드를 붙여넣는 것**.
   - 문안·UTM·전달 계기는 referrals 와 같이 쓴다.
3. **스레드 — 시험 1회.** 알고리즘 피드라 팔로워 수가 천장이 아니다. 한국어권 부모에게 네이버를 거치지 않고 닿을 수 있다는 **가설**(n=1). 글 1개 · UTM 링크 · 2주 판정 (`EXPERIMENT-NOW` §3-5 "다음 시험", 승인 대기).
4. **인스타 — 아카이브·프로필 신뢰용.** 도달을 기대하지 않는다. 프로필 링크 `/ig`, 실제로 사람을 보내는 건 **스토리 링크 스티커**뿐(캡션 주소는 눌리지 않는다).
5. **페이스북 개인 프로필 — 하지 않는다.** 친구 0.

LinkedIn·X·TikTok·텔레그램은 원본에 있지만 MHJ 의 채널이 아니다. 계정을 새로 만들자는 제안은 숫자·출처 없이 하지 않는다.

## 시작 전에 확인할 것

이미 있으면 묻지 않는다.

1. **원재료** — 어느 글/매거진 호/영상인가. 슬러그.
2. **어느 채널** — 위 우선순위 중 어디.
3. **누가 올리나** — 유씨·PeNnY 가 손으로 올린다. Claude 는 초안만.
4. **사진·영상 재료** — 아이 얼굴 없는 것이 있는가 (아래 개인정보 체크리스트).
5. **언어** — 한국어·영어·둘 다. 스레드·카톡 카드는 한국어, WhatsApp 카드는 영어. 유튜브 쇼츠의 **말**은 글 언어를 따르고, 글이 영어인데 한국 부모에게도 닿아야 하면 **한국어 자막판**을 하나 더 만든다(같은 영상, 자막만 교체).

## 콘텐츠 기둥

원본의 "3~5개 기둥" 틀을 MHJ 에 맞추면:

| 기둥 | 역할 | 예 |
|---|---|---|
| 정보형 "문" | 새 사람을 데려온다 | 입학 나이, 성적표 용어, NCEA 변경, 텀 방학 |
| 가족 에세이 "집" | 온 사람이 남는다 | 세 딸의 학교생활, 이민 첫해 |
| 마이랑이 일상·장소 | 지역 신뢰 | 도서관, 바닷가, 동네 가게 |
| 매거진·이달의 책 | 브랜드 | 새 호, Min/Hyun/Jin 의 책 기록 |

"정보형이 문을 열고, 에세이가 집이 된다" (`PLAN-distribution` §3). 소셜에서 새 사람을 부르는 것은 거의 언제나 **정보형**이다.

## 글 하나 → 여러 조각 (재활용)

원본의 "콘텐츠 원자" — 혼자 떨어져도 뜻이 통하는 조각 — 를 뽑는다.

| 원재료 | 조각 | 채널 |
|---|---|---|
| 블로그 정보형 글 | 질문 1개 + 답 2~3개 (아래 쇼츠 구조) | 유튜브 쇼츠, 스레드 |
| 블로그 정보형 글 | 답 3~4줄 요약 카드 | 카톡·WhatsApp 단톡방, 인스타 스토리 |
| 블로그 정보형 글 | 단계·목록 | 인스타 캐러셀 (슬라이드 묶음) |
| 가족 에세이 | 한 장면 + 한 문장 | 스레드, 인스타 게시물 |
| 매거진 호 | 표지 + 기사 세 줄 | 인스타, 유튜브 설명란 |

- 조각마다 **앞 맥락 없이 읽혀야** 한다.
- 원재료에 없는 사실을 조각에서 새로 만들지 않는다. 사실(나이·날짜·규칙)은 글의 `summary_ko`·인포블록·본문에서만 옮긴다(`summary_ko` 가 비어 있으면 본문에서). 의심되면 → fact-verify.
- 같은 조각을 3~6개월 뒤 다시 써도 된다 (철이 돌아올 때: 입학 11~2월, 성적표 6~7월).

## 후크 — 첫 줄이 전부다

원본 공식을 자연스러운 한국어로. 공식은 모양일 뿐, **구체적인 사실·숫자·장면**으로 채워야 한다.

- **궁금증**: "뉴질랜드는 몇 살에 학교에 가는지, 저희도 처음엔 틀렸어요." / "성적표의 consolidating, 나쁜 뜻이 아니었어요."
- **이야기**: "첫 등교 날, ⟨Min/Hyun/Jin⟩ 의 ⟨실제 장면⟩." / "⟨N⟩년 전 마이랑이에 처음 왔을 때 제일 헷갈렸던 건 학교였어요."
- **쓸모**: "NZ 학교 입학 전에 알아야 할 네 가지." / "학군(Home Zone)은 집 계약 전에 보세요."
- **통념 뒤집기**: "대략 5월 이후에 입학하면 그해는 Year 0 으로 셉니다. 한국식으로 세면 한 해가 어긋나요."

이야기 후크의 ⟨ ⟩ 는 **실제로 있었던 일**로만 채운다. 그럴듯한 장면을 지어내지 않는다.

MHJ 톤에서 빼는 것: "충격", "아무도 안 알려주는", "이거 모르면 손해", 분노·불안 자극형. 따뜻하되 세련되게.

**무거운 주제(아동 안전·학대 예방·건강·이민 신분)** — 후크는 불안이 아니라 **아이가 배우는 것·부모가 할 수 있는 것**으로 연다. 통계·피해 사례는 소셜 조각으로 옮기지 않는다(원문에 단서가 붙은 숫자는 특히). 링크로 글 전체를 읽게 한다.

**사실 자체가 대조일 때**(예: "예전엔 stranger danger, 지금은 상황 판단") — "~가 아니라 ~다" 틀 대신 **바뀐 것을 시간 순서로** 쓴다: "예전에는 낯선 사람을 조심하라고 가르쳤어요. 지금은 '어, 이상한데' 하는 느낌을 믿으라고 가르쳐요."

## AI 티 금지

AI 가 쓴 것처럼 읽히면 사람은 넘겨 버린다. 한국어에서 특히 잘 보이는 것들:

- **대조 반전**: "~가 아니라 ~다", "단순한 ~이 아닌 ~". 말하고 싶은 쪽을 이유와 함께 바로 쓴다.
- **부정 나열**: "~도, ~도, ~도 없이". 실제로 일어나는 일을 쓴다.
- **꼬리 붙이기**: 문장을 다 말한 뒤 쉼표로 같은 말을 덧붙이기. 주장에서 문장을 끝낸다.
- **자문자답·콜론 반전**: "결과는? 3배." "핵심은 바로: ~". (FAQ 의 질문, 독자 목소리의 질문은 괜찮다.)
- **상투어**: "~의 모든 것", "완벽 정리", "꿀팁 대방출", "알아보도록 하겠습니다", "~해 보는 건 어떨까요?", "새로운 차원의".
- **긴 줄표(—)** 를 게시물 본문에 쓰지 않는다. 마침표나 줄바꿈으로.
- **한 줄씩 끊어 쓰기**를 처음부터 끝까지 반복하지 않는다. 문단으로 쓰고, 사람이 숨 쉴 자리에서 줄을 바꾼다.
- **참여 낚시**: "공감하시면 좋아요", "저장 필수", "다시 읽어 보세요". 요점에서 끝내거나, 정말 답을 듣고 싶은 질문 하나.
- **꾸민 고백**: 실제 이야기 없는 "솔직히 말하면 너무 무서웠어요…".
- **이모지 불릿**: 모든 줄 앞 이모지 금지. 인스타 캡션의 짧은 목록 하나(✔️) 정도까지만.

조각난 문장과 "셋 나열"은 게시물당 한 번까지.

## 쇼츠·릴스 — 짧은 영상

- **3초 규칙**: 첫 1초 안에 화면(장면) + 말 + 자막 문구 세 가지가 같이 들어간다.
- **구조 (30~60초)**: 질문(0~3초) → 우리 집에서 겪은 장면(3~15초) → 답 2~3개(15~50초) → "자세한 건 설명란 링크"(마지막 5초).
- **자막 필수**: 대부분 소리 없이 본다. 한 화면 2줄까지, 한 줄은 짧게(3~5어절), 말과 정확히 맞춘다.
- **자주 하는 실수**: 앞을 길게 끌기 · 자막 없음 · 나쁜 음질 · 필요 이상 길이 · 마지막에 무엇을 하라는 말 없음.
- 음악은 플랫폼 음원 라이브러리 안에서. 저작권 음악 금지.

대본 틀·플랫폼별 글자 수·해시태그 한도: [references/platform-specs.md](references/platform-specs.md) (변동 가능 — 게시 전 확인)

## 링크 — 어디서 왔는지 남긴다

| 자리 | 링크 |
|---|---|
| 유튜브 채널·영상 설명 고정 자리 | `https://www.mhj.nz/yt` |
| 인스타 프로필 | `https://www.mhj.nz/ig` |
| 글 1편을 가리키는 게시물 | `https://www.mhj.nz/blog/<슬러그>?utm_source=<youtube·instagram·threads·kakaotalk>&utm_campaign=<슬러그>` |
| WhatsApp 그룹에 올리는 카드 | `?utm_source=whatsapp&utm_campaign=<슬러그>` — 별칭이 없어 `referral` 로 기록된다. WhatsApp 미리보기 봇은 `lib/traffic-source.ts` 봇 목록에서 이미 걸러진다 |

- 짧은 주소는 **홈으로** 간다. 글로 보내려면 긴 UTM 링크를 쓴다.
- 인스타 캡션 속 주소는 눌리지 않는다 → 스토리 링크 스티커에 UTM 링크.
- `utm_source` 는 소문자 영문만. `threads`·`kakaotalk`·`youtube`·`instagram` 은 이미 수집 코드가 안다.

## 측정

- **원수치 · 체류 5초 이상 · 2페이지 이상**을 나란히 본다. 링크를 새로 올리면 플랫폼이 점검하러 들어와 사람처럼 찍힌다 (US·체류 0초·같은 1분에 몰림).
- 스냅샷: `node --env-file=.env.local scripts/report-traffic-snapshot.mjs --write`
- 주간 지표: 외부 유입 세션(체류 있는 것) · 채널·캠페인별 세션 · 구독자 순증 · 구체적 반응(댓글·질문·DM).
- **성과가 아닌 것**: 게시 횟수, 좋아요, 팔로워 수 변화만 따로 보기.
- 판정 기준은 미리 적는다. 예: "2주 안에 체류 5초↑ + 2페이지↑ 세션이 1개라도 더 나오면 정식 경로로."

## 질문 줍기 (원본의 "소셜 리스닝"을 줄인 것)
