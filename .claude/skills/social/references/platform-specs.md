## 1. 글자 수·해시태그

### 유튜브 (쇼츠 포함)

| 항목 | 한도 |
|---|---|
| 제목 | 최대 100자 · 잘리기 전 보이는 건 약 70자 |
| 설명 | 최대 5,000자 · "더보기" 전 보이는 건 약 100자 |
| 해시태그 | **15개를 넘기면 전부 무시됨** · 권장 3~5개 · 쇼츠는 1~5개 |

- 설명의 앞 3개 해시태그는 제목 위에 링크로 뜬다.
- 설명 **첫 100자 안에** 글 링크(또는 `mhj.nz/yt`)를 넣는다. 그 뒤는 대부분 안 읽힌다.
- 영상 비율 9:16. 원본 기준 쇼츠 권장 길이 30~60초. "유튜브 검색이 적용되니 제목을 검색어처럼" 쓴다.

### 스레드

| 항목 | 한도 |
|---|---|
| 본문 | 500자 (텍스트 첨부 시 최대 10,500자 = 500 + 펼침 10,000) |
| 주제 태그 | **게시물당 1개** |
| 펼치지 않고 보이는 부분 | 첫 1~2줄 |

- 해시태그로 퍼지는 곳이 아니다. 첫 1~2줄이 후크다.

### 인스타그램

| 항목 | 한도 |
|---|---|
| 캡션 | 최대 2,200자 · "더보기" 전 약 125자 |
| 해시태그 | **최대 5개**(원본 표기 "공식 한도") · 권장 3~5개 |
| 캐러셀 | 1080×1350(4:5) · 최대 20장 |

- 캡션 속 주소는 눌리지 않는다. 링크는 **스토리 링크 스티커**와 프로필 링크(`mhj.nz/ig`)뿐.
- ⚠️ `docs/kit-1b-kakao-2026-09-22.txt` 의 한국어 인스타 캡션은 해시태그를 6개 썼다. 다음 키트부터 5개 이하로.

### 페이스북 (참고 — 지금은 쓰지 않음)

| 항목 | 한도 |
|---|---|
| 본문 | 최대 63,206자 · 반응이 좋은 길이 40~80자 |
| 해시태그 | 한도 없음 · 효과 거의 없음, 1~2개 |

### 공통

- 해시태그도 글자 수에 들어간다.
- 잘리는 지점 **앞에** 요점을 둔다.
- 해시태그는 적을수록 낫다. 아이 실명·학교명이 들어간 태그는 절대 쓰지 않는다.

## 2. 쇼츠·릴스 대본 틀

```markdown
## 영상: <가제>

**채널:** 유튜브 쇼츠 / 인스타 릴스
**길이:** <30~60>초
**형식:** <말하는 얼굴 없이 — 손·풍경·글자 화면 / 사진 넘기기 / 화면 녹화>
**원재료:** <블로그 슬러그> (사실은 여기서만 옮긴다)

### 후크 (0~3초)
- 화면: <첫 장면 — 아이 얼굴 없음>
- 말: <질문 한 문장>
- 자막: <짧게, 3~5어절>

### 본문 (3~50초)
- [3~15초] <우리 집에서 실제로 겪은 장면 한 개>
- [15~50초] <답 2~3개 — 하나당 5~8초>

### 마무리 (마지막 5초)
- 말: <"자세한 건 설명란 링크에 정리해 뒀어요">
- 자막: <글 제목 짧게>
- 설명란 첫 줄: <UTM 링크 또는 mhj.nz/yt>

### 제작 메모
- 음악: <플랫폼 음원 라이브러리 안에서 · 목소리 아래로 낮춤>
- 필요한 장면: <목록>
- 개인정보: 얼굴·학교명·위치 태그 없음 확인
```

얼굴 없이 만드는 형식이 MHJ 에 맞다:
- **사진 넘기기** — 장마다 2~4초, 자막으로 요점, 목소리나 잔잔한 음악.
- **풍경 위주(B-roll)** — 1~3초씩 짧게 끊고, 목소리 박자에 맞춘다.
- **화면 녹화** — 학교 안내문·성적표 양식처럼 개인정보 없는 화면만. 중요한 부분을 확대한다.

결과를 읽는 법(원본): 끝까지 본 비율이 낮으면 후크를 바꾼다 · 조회는 많은데 구독이 없으면 마지막 안내와 주제 적합성을 본다 · 저장은 많은데 공유가 적으면 "쓸모는 있는데 넘길 이유가 없는" 내용이다.

## 3. 인스타 캐러셀 틀 (원본 다섯 가지 중 MHJ 에 맞는 셋)

공통 규칙: **1장이 썸네일이다** — 뒤에 장이 더 있는 줄 모르는 사람이 1장만 보고 멈춰야 한다. 안쪽 장은 같은 틀(배치·글자 크기·색).

| 틀 | 언제 | 구성 |
|---|---|---|
| **목록형** (원본 Value-Stack) | 준비물·체크리스트·용어 | 1장: 정확한 개수 + 무엇 ("NZ 입학 첫 주 준비물 ⟨N⟩가지") → 장마다 하나씩 → 마지막: 할 일 하나 |
| **경험→방법** (원본 Problem-Proof) | 우리가 겪고 알아낸 것 | 1장: 실제 겪은 일 → 진짜 헷갈린 점 → 우리가 한 방법 → 마지막: 실물(양식·사진, 개인정보 가림) |
| **단계형** (원본 Demo Walkthrough) | 절차 (등록·신청) | 1장: 결과 → 막혔던 점 → 전체 단계 개수 먼저 → 단계마다 한 장 → 마지막: 정리 |

- 표지에 약속한 개수는 정확히 지킨다. 채우려고 장을 늘리지 않는다.
- 숫자·사실은 원글에 있는 것만.
- 글자는 썸네일 크기에서도 읽히게(1080px 폭 기준 약 28pt 이상).
- 마지막 장의 할 일은 **하나** — 보통 "스토리 링크에서 전체 글".
- 캡션은 1장을 반복하지 말고 따로 후크로 쓴다.

원본의 "분노형(Rant Callout)"·"꿀팁 목록(Hack List)" 틀은 MHJ 톤과 맞지 않아 뺐다.
