# AI 가 꺼내 가기 쉬운 블록 모양 (MHJ)

`SKILL.md` §3 4단계·§4 의 보충이다. AI 는 페이지가 아니라 **문단**을 뽑는다. 그래서 핵심 문단 하나가 앞뒤 없이 읽혀도 뜻이 서야 한다.

**규칙 셋**
1. 블록의 사실은 **본문·FAQ·인포블록에 이미 있는 것**만. 새 사실이 필요하면 `[NEED: 출처]` 로 두고 `fact-verify` 를 거친다.
2. Yussi 본문 문장을 다시 쓰지 않는다. 블록은 제목·첫 문단·FAQ·H2 **제안**으로 낸다.
3. 구글은 "AI 를 위해 잘게 쪼개지 말라"고 한다. 블록은 사람이 읽기에도 자연스러운 정리여야 한다. 블록만 늘어선 글은 실패다.

아래 예시의 `{ }` 칸은 실제 글에서 채운다. 채운 문장은 **예시**가 아니라 근거 위치를 적은 제안이 된다.

---

## 1. 정의 블록 — "~가 뭐야?" 질문

```
## What does "{용어}" mean on a NZ school report?

"{용어}" means {한 문장 뜻 — 본문 근거}. {이 단계가 어디쯤인지 한두 문장}. {우리 집에서 이 말을 처음 봤을 때 한 문장}.
```

- 첫 문장만 잘려 나가도 답이 된다.
- 마지막 문장이 MHJ 몫이다 — 정부·학교 안내에는 없는 경험.

## 2. 단계 블록 — "어떻게 해?" 질문

```
## How to {행동}

{한 문장 개요}.

1. **{단계 이름}**: {1~2문장}
2. **{단계 이름}**: {1~2문장}
3. **{단계 이름}**: {1~2문장}
```

- 단계 수는 실제 단계 수만큼. 3개로 맞추지 않는다.
- 공식 절차(등록·서류)가 들어가면 `*.govt.nz` 출처와 확인 날짜를 붙인다.

## 3. 비교표 — "A 와 B 차이" 질문

```
## {A} vs {B}: {한 줄 설명}

| | {A} | {B} |
|---|---|---|
| {기준 1} | | |
| {기준 2} | | |
| 우리 집 경우 | | |
```

- 예: Year 0 과 Year 1, mid-year report 와 end-of-year report, Primary 와 Intermediate.
- "우리 집 경우" 줄은 경험이 있을 때만. 없으면 줄을 지운다.

## 4. FAQ 블록 — 주변 질문

```
### {사람이 실제로 치는 문장}?

{첫 문장에 답}. {보충 1~2문장}.
```

- 질문 문장은 GSC 검색어에서 가져온다. 예: `keeping ourselves safe junior primary` → "Which year levels learn Keeping Ourselves Safe?" 답은 본문의 "Junior Primary (Years 0–3)" 구분(`gsc-2026-09-23.md` §11). **이 예시는 2026-09-24 에 이미 반영됐다** — 제안 전에 라이브 FAQ 와 겹치는지 먼저 본다.
- 3~5개. 답은 50~100단어 안. 본문에 없는 답은 만들지 않는다.
- FAQ 는 구글 클릭을 노리는 장치가 아니다(FAQ 리치 결과 2026-05-07 제거). 답을 꺼내 두는 장치다.

## 5. 근거 샌드위치 — 사실 + 출처 + 경험

```
{주장 한 문장}. According to {기관/페이지 이름} ({확인 날짜}), {근거 한 문장}. {그래서 우리 집에서는 어땠는지 한 문장}.
```

- 출처는 실제로 열어 본 페이지만(`fact-verify` §1 링크 검사).
- 숫자는 출처에 있는 그대로, 날짜와 함께. 반올림·추정·"약 70%" 같은 만들어 낸 값 금지.

## 6. 자체 완결 답 블록 — 핵심 한 문단

```
**{질문 핵심}**: {앞뒤 없이도 뜻이 서는 2~3문장 답}.
```

- 글의 첫 문단 자리에 둔다(발행 폼 `answer_first` 40~60단어).
- "this", "as mentioned above" 처럼 앞 문맥에 기대는 말을 쓰지 않는다.

## 7. 경험 블록 — MHJ 추가

원본 스킬에는 없다. MHJ 가 정부·학교 사이트와 다른 유일한 이유라서 넣는다.

```
**What it looked like for us**: {날짜·학년·장소가 있는 구체 장면 1~2문장}. {거기서 배운 것 한 문장}.
```

- 아이는 Min/Hyun/Jin 으로만. 학교 이름·얼굴·위치를 특정하는 정보는 넣지 않는다.
- Yussi 가 이미 쓴 장면에서 가져온다. 장면을 지어내지 않는다.

## 사실 묶음 표 — 질문 펼치기에 대비

AI 는 한 질문을 여러 하위 검색으로 펼친다. 검색 문장은 매번 달라도 밑에 있는 **사실 묶음**은 비슷하다. 묶음마다 담당 글 하나를 정한다.

| 사실 묶음 | 관찰/추정 | 독자가 원하는 것 | 지금 인용되는 출처 | 우리 담당 글 | 빈 곳 |
|---|---|---|---|---|---|
| 입학 나이·학년 | 관찰(GSC) | 몇 살에 몇 학년으로 | {프로브 결과} | `starting-school-in-new-zealand` | {예: 하루 시작 시각 — 글에 답 없음} |
| 성적표 용어 | 관찰(GSC) | consolidating 등 단어 뜻 | {프로브 결과} | `how-to-read-a-mid-year-report` | {예: mid-term 표현} |
| 안전 교육 프로그램 | 관찰(GSC) | 몇 학년이 무엇을 배우나 | {프로브 결과} | `nz-keeping-ourselves-safe` | — |

- "관찰"은 GSC·프로브에서 실제로 본 것, "추정"은 우리가 짐작한 것. 추정 줄은 가설로 표시한다.
- **기존 글을 먼저 고치거나 묶는다.** 새 글은 진짜 빈 곳이 있을 때만. 펼친 질문마다 글을 만들지 않는다.
- 빈 곳에 답할 사실이 우리에게 없으면(예: 하루 시작 시각) 지어내지 않는다. 두 분이 답할 수 있으면 FAQ 한 줄 후보로 사용자에게 넘긴다.

## 주제별 신뢰 신호

| 주제 | 붙일 것 |
|---|---|
| 학교·교육 제도 | `education.govt.nz`·`ero.govt.nz`·학교 공식 안내 링크, 확인 날짜, 학년 구분을 정확히 |
| 비자·이민 | `immigration.govt.nz` 링크와 확인 날짜, "편집상 정확성을 위한 정보이며 법률 조언이 아님"(`fact-verify` 면책 문구) |
| 동네 장소·행사 | 공식 페이지 링크. 운영 시간·요금은 확인 날짜 없으면 쓰지 않는다 |
| 생활 경험 | 날짜·계절·학년이 있는 장면. 일반론으로 뭉개지 않는다 |
